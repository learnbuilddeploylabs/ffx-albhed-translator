# 📖 Final Fantasy X Al Bhed Translator

Don't want to wait until you've collected all of the Al Bhed Primers scattered across Spira?

I got you!

---

## 📌 What This Program Does

- Lets you select which language to translate to (English or Al Bhed... obviously)
- Preserves capitalization, spaces, numbers, and punctuation
- Allows you to continue translating or switch languages without restarting the program

---

## 🛠 Requirements

- Python 3.x
- A terminal or command prompt
- No additional libraries required

### 🚀 How to Run

1. Download `translator.py` from this repository.
2. Make sure Python 3 is installed.
3. Open a terminal or command prompt in the folder containing the file.
4. Run the following command:

```bash
python translator.py
```

*Depending on your operating system, you may need to use `python3 translator.py` instead.*

Follow the on-screen prompts to start translating!
